<Explanation id="intro">

**Horizontal scaling** means spreading data (or load) across multiple
machines instead of making one machine bigger. **Sharding** is how you
decide which machine owns which piece of data. The simplest strategy is
**range-based sharding**: divide the key space into contiguous ranges,
one per shard — like assigning user IDs 0-999 to shard 0, 1000-1999 to
shard 1, and so on.

```python
def shard_for_key(key, boundaries):
    for i, boundary in enumerate(boundaries):
        if key <= boundary:
            return i
    return len(boundaries)
```

</Explanation>
