<Explanation id="intro">

**Reference counting** is one of the simplest real garbage collection
strategies: every object tracks how many live references point to it.
Creating a new reference increments the count; dropping one decrements
it; the moment the count hits zero, nothing in the program can reach
that object anymore, so it's safe to free immediately.

```python
def simulate_refcounts(operations):
    refcounts = {}
    freed = []
    for kind, obj_id in operations:
        if kind == "alloc":
            refcounts[obj_id] = 1
        elif kind == "ref":
            refcounts[obj_id] += 1
        elif kind == "unref":
            refcounts[obj_id] -= 1
            if refcounts[obj_id] == 0:
                freed.append(obj_id)
                del refcounts[obj_id]
    return freed
```
