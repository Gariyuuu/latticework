<Explanation id="intro">

Most languages split memory into (at least) two regions with very
different behavior. The **stack** holds each function call's local
variables and return address as a **frame**, pushed on call and popped
on return — fast, automatic, but FIXED SIZE, which is exactly why deep
or infinite recursion crashes with a stack overflow. The **heap** holds
dynamically-allocated data that can outlive the function that created
it (an object returned from a function, a growable list) — flexible,
but slower to allocate and (in languages without a garbage collector)
manually managed.

```python
def simulate_call_stack(calls, max_depth):
    stack = []
    for event in calls:
        if event[0] == "call":
            stack.append(event[1])
            if len(stack) > max_depth:
                return "stack overflow"
        elif event[0] == "return":
            stack.pop()
    return "ok"
```

</Explanation>
