<Explanation id="intro">

A **graph** is nodes plus edges between them — more general than a tree
(which is just a graph with no cycles and exactly one path between any two
nodes). The most common representation in code is an **adjacency list**: a
dict mapping each node to the list of nodes it connects to.

```python
graph = {
    "A": ["B", "C"],
    "B": ["D"],
    "C": ["D"],
    "D": [],
}
```

**BFS** (breadth-first search) explores level by level using a queue —
first all of `start`'s direct neighbors, then their neighbors, and so on.
It's what you want for "shortest path in an unweighted graph."

</Explanation>

<CodeExample id="try-it" language="python" code={`from collections import deque\n\ndef bfs_order(graph, start):\n    visited = {start}\n    order = []\n    queue = deque([start])\n    while queue:\n        node = queue.popleft()\n        order.append(node)\n        for neighbor in graph[node]:\n            if neighbor not in visited:\n                visited.add(neighbor)\n                queue.append(neighbor)\n    return order\n\nprint(bfs_order({"A": ["B", "C"], "B": ["D"], "C": ["D"], "D": []}, "A"))\n# ['A', 'B', 'C', 'D']`} caption="Marking a node visited the moment it's enqueued (not when it's dequeued) is what prevents the same node from being added to the queue twice." />

<Explanation id="dfs">

**DFS** (depth-first search) explores as deep as possible down one branch
before backtracking — using a stack (or recursion, which uses the call
stack implicitly). It's the natural fit for "does a path exist at all,"
cycle detection, and topological sort (you'll build one in the Algorithms
course).

```python
def has_path(graph, start, end):
    visited = set()
    def dfs(node):
        if node == end:
            return True
        visited.add(node)
        return any(
            neighbor not in visited and dfs(neighbor)
            for neighbor in graph[node]
        )
    return dfs(start)
```

</Explanation>
