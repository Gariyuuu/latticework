<Explanation id="intro">

Snowflake's core architectural idea: STORAGE (your data) and COMPUTE
(the "virtual warehouses" that query it) are completely separate.
Multiple warehouses — sized independently, billed independently — can
query the exact same data at the same time with zero contention.
Warehouse sizes follow a doubling "T-shirt size" scale: each size up
doubles both the compute power and the credits-per-hour cost.

```python
def warehouse_cost(size, hours, credit_price=3.0):
    size_credits = {"X-Small": 1, "Small": 2, "Medium": 4, "Large": 8, "X-Large": 16}
    credits = size_credits[size] * hours
    return round(credits * credit_price, 2)
```

</Explanation>
