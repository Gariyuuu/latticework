<Explanation id="intro">

Environment variables are the shell's way of passing configuration around
without hard-coding it: `export NAME=value` sets one, and `$NAME`
substitutes its current value into any later command. A handful are set
for you automatically — `$HOME` (your home directory) and `$PWD` (your
current directory, always kept in sync by `cd`) are the two you'll lean on
most. Using a variable instead of a literal value is what lets the exact
same script work correctly across different users, machines, or
environments.

```bash
export EDITOR=nano
echo "using $EDITOR"
# using nano
echo config for $EDITOR > $EDITOR.conf
cat $EDITOR.conf
# config for nano
```

</Explanation>
