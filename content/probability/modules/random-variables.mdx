<Explanation id="intro">

A **random variable** is a numeric outcome of something uncertain — the
result of a die roll, tomorrow's stock return, how many bugs are in a
release. For a **discrete** random variable (finite or countable
outcomes), the **PMF** (probability mass function) lists every possible
outcome and how likely it is.

```python
# A fair six-sided die
pmf = {1: 1/6, 2: 1/6, 3: 1/6, 4: 1/6, 5: 1/6, 6: 1/6}
print(round(sum(pmf.values()), 10))   # 1.0 -- every valid PMF sums to 1 (rounding here just clears floating-point noise like 0.9999999999999999)
```

</Explanation>

<CodeExample id="try-it" language="python" code={`# Estimate a PMF from observed data\nrolls = [1, 3, 3, 5, 6, 3, 2, 6, 1, 3]\ncounts = {x: rolls.count(x) for x in set(rolls)}\ntotal = len(rolls)\npmf = {x: round(c / total, 3) for x, c in counts.items()}\nprint(pmf)  # {1: 0.2, 2: 0.1, 3: 0.4, 5: 0.1, 6: 0.2}`} caption="Estimating a PMF from data is just counting how often each outcome occurred, then dividing by the total — the empirical distribution." />

<Explanation id="expectation">

The **expected value** E[X] is the probability-weighted average of every
possible outcome — not necessarily a value X can actually take (the
expected value of a fair die is 3.5, which the die can never actually
show).

```python
pmf = {1: 1/6, 2: 1/6, 3: 1/6, 4: 1/6, 5: 1/6, 6: 1/6}
expected = sum(value * prob for value, prob in pmf.items())
print(expected)   # 3.5
```

That's the same "weight times value, summed" pattern from the NumPy
linear algebra course — expectation is a dot product between outcomes
and their probabilities.

</Explanation>
