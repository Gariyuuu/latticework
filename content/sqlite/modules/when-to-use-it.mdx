<Explanation id="intro">

SQLite is an excellent default for local, single-process, embedded
storage — but it has real limits that make a client-server database the
better choice past a certain point: it locks the whole file during
writes (so many concurrent writers serialize rather than running in
parallel), and it isn't designed to be accessed directly over a network
by multiple separate application servers.

```python
def should_use_sqlite(concurrent_writers, data_size_gb, needs_network_access):
    if needs_network_access:
        return False
    if concurrent_writers > 1:
        return False
    if data_size_gb > 100:
        return False
    return True
```

</Explanation>
