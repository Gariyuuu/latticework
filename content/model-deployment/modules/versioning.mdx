<Explanation id="intro">

Deploying a new model version instantly to 100% of traffic means any
regression — a bug, a subtle accuracy drop, a latency spike — hits every
single user immediately. A **canary rollout** instead ramps up
gradually: start the new version on a small slice of traffic (say 5%),
watch its error rate, and only increase that slice if things look
healthy. Any regression only affects a small fraction of traffic while
it's being caught, and can be rolled back to 0% instantly.

```python
def next_canary_stage(current_pct, error_rate, error_threshold=0.05, cap=100):
    if error_rate > error_threshold:
        return 0
    next_pct = min(current_pct * 2, cap) if current_pct > 0 else 5
    return next_pct
```
