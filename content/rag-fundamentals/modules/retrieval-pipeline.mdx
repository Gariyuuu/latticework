<Explanation id="intro">

This module wires together two things you've already built: Embeddings'
cosine similarity (rank candidates by relevance) and LLM Fundamentals'
context-window awareness (respect a hard token limit). A real RAG
pipeline does exactly this — embed the query, score every candidate
chunk by similarity, then greedily pack the most relevant chunks into
the prompt until the token budget available for retrieved context runs
out.

```python
def cosine_similarity(a, b):
    dot = sum(x * y for x, y in zip(a, b))
    mag_a = sum(x ** 2 for x in a) ** 0.5
    mag_b = sum(x ** 2 for x in b) ** 0.5
    return dot / (mag_a * mag_b)

def retrieve_within_budget(query, candidates, token_budget):
    scored = sorted(candidates, key=lambda c: -cosine_similarity(query, c[1]))
    selected = []
    used = 0
    for chunk_id, vector, token_count in scored:
        if used + token_count <= token_budget:
            selected.append(chunk_id)
            used += token_count
    return selected
```
