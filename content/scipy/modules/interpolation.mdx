<Explanation id="intro">

Given a handful of known `(x, y)` points, **interpolation** estimates
`y` at some NEW `x` that falls between them — assuming some smooth
relationship connects the known points. The simplest version, linear
interpolation, just draws a straight line between each pair of adjacent
known points and reads off where the query `x` lands on that line.

```python
from scipy.interpolate import interp1d

def interpolate_value(x_known, y_known, x_query):
    f = interp1d(x_known, y_known)
    return round(float(f(x_query)), 4)
```

</Explanation>
