<Explanation id="intro">

Unlike AWS IAM's explicit-deny-wins evaluation, GCP's basic IAM model is
simpler and purely ADDITIVE: a user's total permissions are just the
union of every role they're bound to. There's no built-in "deny"
mechanism at this level — if any bound role grants a permission, the
user has it, full stop. (GCP does offer more advanced conditional/deny
policies for finer control, but the base model is additive-only.)

```python
def has_permission(role_bindings, permission, role_permissions):
    for role in role_bindings:
        if permission in role_permissions.get(role, set()):
            return True
    return False
```

</Explanation>
