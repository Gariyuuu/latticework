<Explanation id="intro">

Before building anything sophisticated, every ML project needs a
**baseline** — the simplest reasonable approach (a constant prediction,
a simple heuristic, or a basic model) that any "real" model must beat to
justify its added complexity. A new model's metric being HIGHER than the
baseline isn't automatically meaningful, though — training and
evaluation both have some inherent noise, so a proper comparison checks
for an improvement large enough to trust, not just any improvement at
all.

```python
def significant_improvements(results, baseline_metric, min_improvement=0.02):
    winners = [(name, m) for name, m in results.items() if m - baseline_metric >= min_improvement]
    winners.sort(key=lambda pair: -pair[1])
    return [name for name, _ in winners]
```
