<Explanation id="intro">

A load balancer sits in front of a pool of servers and decides which
one handles each incoming request. The simplest strategy is **round
robin**: cycle through the pool in order, spreading requests evenly.

```python
def round_robin_assignments(servers, num_requests):
    assignments = []
    for i in range(num_requests):
        assignments.append(servers[i % len(servers)])
    return assignments
```

</Explanation>

<Explanation id="weighted">

Plain round robin assumes every server can handle the same load. In
practice, servers often differ in capacity — one instance might have
double the CPU of another. **Weighted round robin** fixes this by
giving each server a share of requests proportional to its weight: a
simple way to implement it is to expand the server list by each
server's weight, then round-robin over the EXPANDED list.

</Explanation>
