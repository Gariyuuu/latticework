<Explanation id="intro">

A pull request merge conflict happens when git can't automatically
combine two branches' changes to the same file. The key insight: git
operates at the LINE-RANGE level, not the whole-file level — two
branches can both edit the same file safely, as long as their edited
line ranges don't overlap. A conflict only appears when both branches
genuinely touched the SAME lines with different content.

```python
def has_conflict(branch_a_changes, branch_b_changes):
    for a_start, a_end in branch_a_changes:
        for b_start, b_end in branch_b_changes:
            if a_start <= b_end and b_start <= a_end:
                return True
    return False
```

</Explanation>
