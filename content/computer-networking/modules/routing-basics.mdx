<Explanation id="intro">

A network is a graph: nodes are routers, edges are links with some
cost (latency, hop count, bandwidth). Finding the best route between
two points is exactly the shortest-path problem from Algorithms'
`graph-algorithms` module — **Dijkstra's algorithm**, applied here to
network latency instead of an abstract edge weight.

```python
import heapq

def shortest_path_cost(graph, start, end):
    distances = {start: 0}
    visited = set()
    heap = [(0, start)]
    while heap:
        dist, node = heapq.heappop(heap)
        if node in visited:
            continue
        visited.add(node)
        if node == end:
            return dist
        for neighbor, weight in graph.get(node, {}).items():
            new_dist = dist + weight
            if neighbor not in distances or new_dist < distances[neighbor]:
                distances[neighbor] = new_dist
                heapq.heappush(heap, (new_dist, neighbor))
    return None
```
